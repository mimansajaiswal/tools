# Journaling Design And Product Archive

This folder preserves the product requirements, implementation status, references, and visual audit artifacts for the journaling app.

- `requirements.md` is the durable product scope distilled from the project discussion.
- `functional-status.md` records what the current worktree proves, what remains incomplete, and which thread owns each remaining issue.
- `screenshots/` contains the current PNG audits that were previously stored at the repository root.

The visual styling is being handled separately. Functional work should avoid overwriting styling decisions unless a visual defect blocks core behavior.
